## RESUMO GERAL (Conteúdo básico que você provavelmente não conhece):

### Atributos Globais:

Atributos globais são aqueles que podem ser aplicados a quase qualquer elemento HTML. É provável que você conheça id, class e style, mas e quanto a lang e title? Se nada vem a sua cabeça, vale pesquisar sobre. Esse é o tipo de conhecimento que não mostra a fatura, mas cobra dívida.

Lembrando que estamos tratando de HTML5 Básico... Existe uma série de outros atributos Globais que você pode não conhecer, mas eu diria que id, class, style, lang e title são as essenciais.

W3School: https://www.w3schools.com/tAGS/ref_standardattributes.asp

### Meta Tags:

Esse é campeão quando o assunto é básico mal ensinado. As meta tags definem metadados sobre o seu documento HTML e são importantíssimas para fazer o seu site ser encontrado... O problema é que elas só são úteis quando você já desenvolveu um site completo, e no intervalo de tempo entre o aprendizado e a utilização real, muitos já se esqueceram de sua existência.

As meta tags são várias, senão centenas, então ninguém seria louco de exigir que você conheça cada uma delas. Ainda assim, para um nível básico, é importante que você saiba da existência delas, tal como o sistema de categorização baseado nos atributos charset, name, property e http-equiv.

WhatWG: https://html.spec.whatwg.org/multipage/semantics.html#the-meta-element

W3School: https://www.w3schools.com/tags/tag_meta.asp

### Tags Semânticas:

Esse é o básico do HTML5 e você provavelmente conhece essas tags de forma geral, mas não confunda entendimento geral com domínio. No geral, se você sabe quando usar as tags &lt;main&gt;, &lt;nav&gt;, &lt;header&gt; e &lt;footer&gt;, entende a diferença de uso entre &lt;section&gt; e &lt;article&gt; e conhece algumas tags menos famosas, como &lt;address&gt; e &lt;aside&gt;, de forma geral, você tem um entendimento bem completo. Senão, vale a pena pesquisar sobre.

W3School: https://www.w3schools.com/html/html5_semantic_elements.asp

TreinaWeb: https://www.treinaweb.com.br/blog/semantica-html-o-que-e-e-por-que-e-importante

### Hierarquia de Títulos:

Suponho que você conheça as tags &lt;h1&gt;, &lt;h2&gt;, &lt;h3&gt;, &lt;h4&gt;, &lt;h5&gt; e &lt;h6&gt;, então serei breve: Você deve usar essas tags pensando na hierarquia (&lt;h6&gt; representando subtópico de &lt;h5&gt;, que representa um subtópico de &lt;h4&gt; e assim por diante), nunca em tamanho de fonte.

Mais uma vez é o básico que cobra dívida quando você menos espera. LLMs costumam fazer um ótimo trabalho com hierarquia de títulos, mas elas provavelmente não vão te avisar se você fizer alguma caquinha.

DeveloperMozilla: https://developer.mozilla.org/pt-BR/docs/Web/HTML/Reference/Elements/Heading_Elements

### Unicode:

Essa não é tão essencial, mas evita uma dor de cabeça mais para frente. Se você quer representar caracteres reservados do HTML5 (como &lt;, &gt; e &amp;) de forma literal em textos, você deve usar a referência de caractere do mesmo. Não precisa decorar (apesar de ser simples e evitar pesquisas frequentes), mas é importante que você saiba como pesquisar quando precisar.

HomeHost: https://www.homehost.com.br/blog/tutoriais/caracteres-especiais-acentos-html/

### Tags &lt;details&gt; e &lt;summary&gt;:

Você provavelmente aprendeu sobre essas, mas por seu uso ser muito específico, é normal se esquecer... O problema é que esse esquecimento as vezes te faz desenvolver uma solução complexa com Javascript para algo que poderia ser feito apenas com HTML e CSS.

WebDev: https://web.dev/learn/html/details?hl=pt-br

## Você nunca vai saber tudo.

Um disclaimer óbvio, mas não custa relembrar... Ferramentas de desenvolvimento mudam o tempo todo, então nós não devemos NUNCA assumir que já conhecemos tudo sobre alguma delas.

Por isso, o primeiro reflexo aqui é sempre a pesquisa. Se você pretende desenvolver uma funcionalidade bem comum em muitos sites, provavelmente existe uma forma de desenvolvê-la só com HTML e CSS. Coloque Javascript na conta e isso se torna uma certeza.

Contudo, se você frequentemente se vê pesquisando um conceito simples, inclusive reencontrando sites que você já visitou antes, esse é um sinal de que você provavelmente está perdendo muita eficiência pesquisando conceitos que deveriam ser automáticos para você.
